## 本次修复

- 外部模型的总结正文、长资料整理、建议提取和问答请求启用完整性检查。
- 服务商明确返回长度截断时，在原供应商安全上限内提高输出 token 额度重试一次；仍截断则抛出明确错误，不把半篇总结缓存或保存为新报告，旧报告保留。
- 完整性检查覆盖 OpenAI 兼容的 `finish_reason` / `native_finish_reason`、嵌套响应和 Anthropic 的 `stop_reason=max_tokens`。它依赖服务商的结束标记，不保证模型内容在语义上完整。
- 此类总结请求发生网络重试时，不再截掉超过 12,000 字符的输入尾部。
- 模型文本生成错误日志仅保留错误信息、代码和 HTTP 状态，避免直接序列化含认证头的 Axios 错误对象。
