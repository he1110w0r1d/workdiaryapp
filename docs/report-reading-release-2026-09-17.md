# 周报与月报阅读版更新（2026-09-17）

## 内容与展示

- 周报围绕本周进展、成果、阻碍和下周跟进；月报围绕阶段成果、反复问题和下月重点。合并同一事项的多次记录，禁止无依据的评分、完成率与环比。
- 周/月报使用应用内编辑规则，避免生产挂载的旧默认模板再次要求逐日列举。个人自定义提示词仍保留，作为语气和专业关注偏好，未覆盖用户设置或服务器公共模板。
- 长资料按带有来源 ID 的记录分段整理，不直接在序列化 JSON 中间截断。
- HTML 由本地 Markdown 渲染器生成，不再让模型写页面。暖灰底、墨绿标题、阅读目录、移动适配与打印样式；新周/月报保存生成时来源摘录。
- 历史总结正文不变。打开网页版时按内容和渲染版本刷新缓存；历史正文要采用新内容结构，需要重新生成一个总结版本。
