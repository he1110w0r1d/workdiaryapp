# 工作日记 UI 改造 · 2026-09-17

## 改动范围

- 统一暖灰白、炭黑、松绿色主题与 Ant Design tokens。欢迎、登录和注册共享页面结构；补全中文页面标题、密码可见切换和自动填充语义。
- 主导航为今天、日记、待办、总结、问答；统计与日历移到数据概览。设置页和头像菜单保留备份、API 管理入口，回收站可从导航与日记进入。
- 今天页提供快速草稿、今天记录、近期工作、临近到期待办和总结入口。草稿按账号保存在当前标签页，转入编辑页后核对时间再提交，不会凭空新增工作记录。
- 日记默认阅读列表，可切换表格；正文侧栏展示，高级筛选折叠。修复日期筛选控件值类型、搜索入口传参、筛选回到第一页和并发响应覆盖。
- 日记编辑保留未提交提醒，并给退出登录增加同类保护。快速记录缓存仅在成功提交后清除。
- 待办、总结、问答、设置和概览统一视觉。任务历史默认收起，有正在执行或失败任务时展开。问答维护入口收起，回答保留来源链接。
- 手机端独立导航抽屉与单栏布局；补充键盘焦点、跳到正文、减少动态效果支持。HTML shell 禁用长期缓存，带哈希的静态资源继续缓存。
